┌──────────────────────────────────────────────────────────────┐
│  🔧 常见问题                                                  │
└──────────────────────────────────────────────────────────────┘

  Q: 启动报错 "Cannot find module 'umi'"
  A: rm -rf node_modules && npm install

  Q: 页面空白不显示
  A: 检查布局组件是否使用了 <Outlet />

  Q: antd 样式异常
  A: 确保 .umirc.js 中 locale.antd: true

  Q: 首次启动很慢
  A: 正常现象，Umi 4 首次需要编译，后续会快很多
