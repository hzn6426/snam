<h2>相关命令</h2>
<ul>
<li>安装依赖包：yarn </li>
<li>项目启动：yarn start </li>
<li>项目打包：yarn build </li>
</ul>
<b>本地开发时请配置config/proxy.js文件，用来指向后端服务</b>
